Идея, которую
можно открыть.

В этом портфолио собраны мои учебные проекты и самостоятельные веб-концепты. Отдельный проект может быть атмосферной обсерваторией, редактором постера или системой финансового учёта.

Кейсы показывают не только внешний вид: рядом с ним есть данные, состояния, экспорт, навигация и ограничения. Для визуальных экспериментов важен резервный режим, для инструментов — предсказуемый результат, для fullstack — согласованность интерфейса и логики.

Концептуальные проекты созданы с AI-помощью в разработке и работе с изображениями. В кейсах отдельно указано, что вымышлено, откуда взяты данные и где заканчивается модель.
